# Her Phase 2 — Automatic Knowledge Extraction

Phase 2 turns the Observer memory into a living story database.

## Added
- Automatic character discovery as names appear in manuscript text.
- Character evidence, appearances, aliases, occupations, and traits.
- Basic relationship discovery from family and relationship phrases.
- Automatic location, organization, and artifact discovery.
- Automatic chapter timeline events.
- Automatic future-idea and plot-thread detection.
- Persistent synchronization into the existing book and chapter records.
- Duplicate protection using normalized names and stable event identifiers.

## Testing
1. Open a book and chapter.
2. Write several sentences containing named characters and locations.
3. Pause briefly or press Observe.
4. Open Characters, Locations, Organizations, Timeline, or Ideas.
5. Confirm discovered records appear and remain after reloading.

Automatic records are editable. Author edits remain the source of truth.
