HER PASSWORD RESET SETUP

What was added
- Forgot Password link on login page
- Six-digit reset code sent by email
- Code expires after 15 minutes
- Only one active code per account
- Resending invalidates the previous code
- Resend button is locked for 30 seconds
- Five incorrect attempts invalidate the code
- Password is securely hashed before saving

Files changed
- backend/controllers/authController.js
- backend/models/User.js
- backend/routes/authRoutes.js
- backend/services/emailService.js (new)
- backend/package.json
- backend/package-lock.json
- backend/.env.example
- pages/auth/login.html
- pages/auth/forgot-password.html
- pages/auth/reset-password.html

Add these values to backend/.env

SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-email@gmail.com
SMTP_PASS=your-google-app-password
EMAIL_FROM="Her <your-email@gmail.com>"

For Gmail, SMTP_PASS must be a Google App Password, not your normal Gmail password.

After replacing the files, run:

cd /c/Her/backend
npm install
node server.js

API endpoints
POST /api/auth/forgot-password
POST /api/auth/reset-password
